Sobre o projeto

Este projeto apresenta a estrutura de um banco de dados desenvolvido para auxiliar no gerenciamento de uma confeitaria.

O banco de dados permite organizar informações relacionadas a clientes, pedidos, produtos, receitas, insumos, estoque, fornecedores e movimentações financeiras.

♡ Organização também é um ingrediente do sucesso! ♡
🗄️

Estrutura do Banco de Dados

O banco de dados é composto por diferentes entidades que se relacionam para organizar as informações da confeitaria.

Cada entidade possui informações específicas e está relacionada com outras entidades para permitir o armazenamento e a organização dos dados.

Entidades do Banco de Dados

O banco de dados é formado por entidades que representam os principais elementos envolvidos no funcionamento da confeitaria.

🍰

CLIENTE

Armazena as informações dos clientes da confeitaria.

🛒

PEDIDO

Registra os pedidos realizados pelos clientes.

📋

ITEM_PEDIDOS

Representa os itens que fazem parte de cada pedido.

🧁

PRODUTO

Armazena os produtos comercializados pela confeitaria.

🏷️

CATEGORIA_PRODUTO

Organiza os produtos em diferentes categorias.

📖

RECEITA

Relaciona os produtos aos insumos utilizados em sua produção.

🥛

INSUMO

Representa os ingredientes e materiais utilizados na produção.

📦

ESTOQUE

Controla as informações relacionadas aos insumos disponíveis.

🚚

FORNECEDORES

Armazena informações dos fornecedores da confeitaria.

🔄

MOVIMENTAÇÃO_ESTOQUE

Registra as movimentações realizadas no estoque.

💳

PAGAMENTO

Registra as informações relacionadas aos pagamentos dos pedidos.

💰

FINANCEIRO

Auxilia no registro das informações financeiras da confeitaria.

👤

USUÁRIO

Representa os usuários responsáveis pelo acesso ao sistema.

🔗

Relacionamentos

As entidades do banco de dados estão relacionadas entre si para permitir que as informações da confeitaria sejam organizadas.

CLIENTE → PEDIDO

Um cliente pode realizar pedidos, e cada pedido está relacionado a um cliente.

PEDIDO → ITEM_PEDIDOS

Um pedido pode possuir vários itens, enquanto cada item pertence a um pedido.

ITEM_PEDIDOS → PRODUTO

Cada item de pedido está relacionado a um produto comercializado pela confeitaria.

PRODUTO → CATEGORIA_PRODUTO

Os produtos podem ser organizados de acordo com suas categorias.

PRODUTO → RECEITA

A receita representa os insumos utilizados na produção dos produtos.

RECEITA → INSUMO

Uma receita utiliza os insumos necessários para produzir determinado produto.

FORNECEDORES → INSUMO

Os fornecedores estão relacionados aos insumos utilizados pela confeitaria.

INSUMO → ESTOQUE

O estoque permite controlar a quantidade disponível dos insumos.

ESTOQUE → MOVIMENTAÇÃO_ESTOQUE

As movimentações registram alterações relacionadas ao estoque.

PEDIDO → PAGAMENTO

Os pagamentos estão relacionados aos pedidos realizados pelos clientes.
